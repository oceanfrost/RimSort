# RimSort Rust rewrite foundation

This directory contains the initial standalone Rust/Slint desktop application. The existing Python application remains at the repository root and is unchanged.

## Run

From this directory, run:

```sh
cargo run
```

The first build resolves and compiles the Rust dependencies. Slint's platform-specific build requirements are documented in the [Slint Rust getting started guide](https://docs.slint.dev/latest/docs/rust/).
